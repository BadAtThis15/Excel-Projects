# Excel-Projects
# 📊 Excel Data Analytics Projects

Welcome to my Excel Projects directory! This folder contains a collection of data analysis, statistical modeling, and data visualization projects executed entirely within Microsoft Excel. 

## 📂 Featured Projects

### 1. Global Digital Adoption Analysis
* **Description:** A research project analyzing global digital adoption trends using cross-sectional datasets sourced from the World Bank.
* **Key Techniques:** Multi-Linear Regression, Statistical Analysis, Data Cleaning.
* **Objective:** To identify and evaluate the core predictors driving digital adoption across various global regions.
* **Files:** `Multi_Variable_Regression_Analysis.xlsx`

## 🛠️ Skills & Tools Demonstrated

* **Statistical Modeling:** Regression Analysis (Linear & Multi-Linear), Trend Analysis.
* **Data Manipulation:** Power Query, Advanced Formulas (XLOOKUP, INDEX/MATCH, Nested Logic).
* **Data Visualization:** Dynamic Dashboards, Pivot Charts, Conditional Formatting.
* **Data Cleaning:** Handling missing values, standardizing cross-sectional data, and outlier detection.

 ## 🚀 How to View
1. Clone this repository or download the `.xlsx` files directly.
2. Open the files in **Microsoft Excel** (Office 365 or 2019+ recommended for optimal formula compatibility).
3. If a project utilizes macros or Power Query connections, ensure you click **Enable Content** when prompted by Excel.
